# 我用AI做了个免费软件目录：三个月收录304款，拒掉了一款付费的

7 月 5 日，我在一个空仓库里提交了第一行代码，项目叫 To Be Free。到 10 月 3 日，它收录了 304 款免费软件、104 个 MCP 服务和 Agent 技能，分成 17 个分类、56 个专题。仓库一共 36 次提交，其中 35 次署了 Claude Code 的名字。

网址是 tobefree.app，代码在 GitHub 上公开。

## 免费软件目录的收录标准：三条硬线

收录只看三件事，缺一条就不收：

- 核心功能永久免费。限时试用不算，免费版阉割到不能用也不算
- 没有广告，不弹窗，不捆绑第三方软件
- 不强制注册，不偷偷上传数据

开源是加分项，不是门槛。304 款里 294 款开源，剩下 10 款是 Everything、Obsidian、达芬奇这类闭源但真免费的。

还有一条：只链官网和官方下载页，站里一个安装包都不放。下载站最常见的坑是改包、捆绑，不托管安装包，这个问题就不存在。

## 拒收的那一款：免费版不能批量生成

8 月 27 日，一位开发者在 GitHub 上推荐了自己的工具 BatchDocMaker。Windows 上的批量文档生成，Excel 里一行数据出一份文档，全部本地运行，不用注册。

推荐信里有一句：免费版不支持批量生成。Pro 版一次性 19 美元，终身授权。

批量生成是这个工具唯一的核心功能。10 月 2 日我回复了拒收，这个 issue 在那里放了 36 天。

同一批另外两份推荐都收了。一个是日语汉字桌面卡片 KanjiWidget，Apache-2.0 协议，作者一个人维护，GitHub 上 4 颗星。另一个是开源收银系统 Posnic，标的是「有免费版」：本地版零价格、不用账号，但浏览器访问和云端同步属于付费的 Posnic Cloud。它的安装包还捆了 MongoDB，MongoDB 用的是 SSPL 协议，所以许可证一栏写成「AGPL-3.0 · 部分组件」，没有直接写 AGPL。

## 我们自己写错过的三条描述

核实别人的工具，也得回头查自己写过的。10 月 2 日一次改了三条旧描述：

| 工具 | 原来写的 | 实际情况 |
|---|---|---|
| uBlock Origin | 支持 Firefox、Chrome、Edge 等主流浏览器 | 完整版只有 Firefox 系能装；Chrome 完成 Manifest V3 迁移后，只能装功能受限的 uBlock Origin Lite |
| Cryptomator | 本地加密云盘文件，没提移动端 | 桌面版完全免费；iOS 和 Android 版免费时只能读，写入要一次性内购 |
| Joplin | 所有笔记都是本地的 Markdown 文件 | 笔记存在本机数据库里，可以随时整批导出成 Markdown |

三条都不算大错。但读者照着旧描述拿 Chrome 去装 uBlock Origin，装上的是另一个东西。

## X / English long-form

# I built a directory of 304 free tools with AI, and turned down a paid one

On July 5 I made the first commit to an empty repo called To Be Free. As of October 3 it lists 304 free tools and 104 MCP servers and agent skills, across 17 categories and 56 curated collections. The repo has 36 commits; 35 of them are co-authored by Claude Code.

It lives at https://tobefree.app/en/ and the source is public on GitHub.

## The three hard rules

A tool gets in only if all three hold:

- Core features are free forever. A timed trial does not count, and neither does a free tier crippled into uselessness.
- No ads, no pop-ups, no bundled third-party software.
- No forced sign-up, no silent uploading of your data.

Open source is a bonus, not a requirement. 294 of the 304 tools are open source; the other 10 are closed but genuinely free, like Everything, Obsidian and DaVinci Resolve.

One more rule: the site links only to official websites and official download pages. It hosts no installers at all. The classic download-site problem, repackaged installers with bundleware, cannot happen if you never host a file.

## The one I turned down

On August 27 a developer suggested their own tool, BatchDocMaker: batch document generation on Windows, one document per spreadsheet row, fully local, no account.

The suggestion included this line: the free version does not support batch generation. Pro is a one-time $19.

Batch generation is the tool's only core feature. I declined on October 2, after the issue had sat there for 36 days.

The other two suggestions in that batch got in. KanjiWidget is a Japanese kanji desktop widget under Apache-2.0, maintained by one person, with 4 GitHub stars. Posnic is an open-source point-of-sale system, listed as "freemium": the local edition costs nothing and needs no account, but browser access and cloud sync belong to the paid Posnic Cloud. Its installers also bundle MongoDB, which is SSPL-licensed, so the licence field reads "AGPL-3.0 · some components" rather than plain AGPL.

## Three entries we got wrong ourselves

Checking other people's tools means re-checking our own entries too. On October 2 we fixed three old descriptions:

- **uBlock Origin.** We said it works on Firefox, Chrome and Edge. Since Chrome's Manifest V3 migration, the full version only installs on Firefox-based browsers; Chrome gets the feature-limited uBlock Origin Lite.
- **Cryptomator.** We did not mention mobile. The desktop apps are fully free; on iOS and Android the free version is read-only, and writing needs a one-time in-app purchase.
- **Joplin.** We said every note is a local Markdown file. Notes live in a local database and can be exported to Markdown at any time.

None of these is dramatic. But a reader who followed the old text and installed uBlock Origin on Chrome got a different extension.

## Traffic: 880 visits a month

From September 2 to October 2, Cloudflare counted 880 visits and 1,590 page views, about 30 visits a day. Just over half came from China, then the US, Singapore and Hong Kong.

Search sends very little: Baidu, Bing and Google together brought about 170 page views. I ping IndexNow after every batch of new tools; search traffic has not moved.

Four people suggested tools on GitHub. The repo has 0 stars.

## A supporter wall, which buys nothing

On October 3 we launched a supporter program. Two ways in:

- Promote: publish anything public that recommends the site and links to it — an article, a video, a post, a newsletter mention.
- Sponsor: GitHub Sponsors, WeChat Pay or Alipay, any amount.

Fill in a short form on GitHub and, once approved, your name goes on the supporter wall. Links there are nofollow, pass no search ranking, and have no effect on which tools are listed or how they rank. Paying to get a tool that fails the rules onto the site is not possible.

The wall is empty right now: https://tobefree.app/en/supporters/
